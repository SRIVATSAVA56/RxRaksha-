Understand medication risks before the next prescription.

Rule-based findings · clear explanations · honest coverage. Every flag shows its source.

HOW IT WORKS

All findings, severities and scores come from a deterministic rule engine — same input, same output. Optional AI can only re-word explanations, and only after human verification. It can never create, remove or regrade a finding.
